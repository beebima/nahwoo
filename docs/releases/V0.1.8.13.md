# NAHWOO V0.1.8.13 — Premium Smart Reader, V4 Level 01–08

## Baseline & decision
- Repo `beebima/nahwoo`, baseline **V0.1.8.12** (`917651dee3edeba0ea22b57dddcd6f1cab1da760`), already contains source V4 Reading-First Level 01–08 with 80 sublevels and 1,600 questions, replacing V3/older materials.
- This release corrects **layout semantics** and protects source-text fidelity rather than re-importing the same 8 × 200 questions again.
- The previous renderer selected colorful card types with *fixed section indices* and only enabled this mapping for lessons with exactly 13 sections. This is incorrect for levels with 12, 14, 15, or 16 sections. Old body/Arabic content could get the wrong card or remain completely flat.
- New mapping uses an explicit catalog of *actual* V4 headings, plus competency taken from each source sublevel; unknown headings fall back to open narrative, not an arbitrary colored card.

## UI spec
- Open headings, narrative paragraphs outside cards; navy main title, blue section heading.
- Source competency shown verbatim in yellow `#FFF5D9`, border `#EDCF7D` with checkmark.
- Arabic examples in blue `#EDF3FF` / border `#CBDCF9`; large RTL Arabic, readable diacritics.
- Breakdown and grammar comparisons in green `#EDF8F1` / `#B9DFC9`; responsive word tiles only when actual alternating Arabic+description pairs are present.
- Exercises and reading practice in violet `#F1EDFF` / `#D3C5EC`.
- Warnings in soft red `#FFF0EE` / `#ECC4BE`.
- Takeaways/quotations in blue `#E7EEFF`, 4px left border.
- Arabic inline uses a 1.14em relative font size, not global `--arabic-size`.
- Dark-mode overrides, narrow viewports, existing independent Latin/Arabic font settings.
- For Cek Cepat, original answer/reason paragraphs remain unchanged but are disclosed behind `<details>` so the question can be attempted before revealing its answer.

## Scope and preserved behavior
- No modifications to 16 higher levels (09–24), dictionary, Mufradat 50+1,200 import, stored learning progress, AdMob, payment, tabs, Android native wrapper or answer state namespace `nahwoo_eval_v4_01812`.
- Existing V4 data content remains unchanged; source parity hash manifest protects all original 80 sublevel material blocks, 1,600 question stems/options/hints, 1,600 answer keys and explanations.
- Does not claim pedagogical/expert review. Some V4 packages explicitly mark themselves as needing expert approval.

## Rollback / preventing repeated errors
- Revert the V0.1.8.13 layout commit, not the V0.1.8.12 V4 content baseline, if a layout bug appears; do not reset user progress.
- Never use `complete13?j:-1` or section index maps for V4; meaning comes from source semantics, not order.
- Keep preview and SHA manifest with package, and update this note plus `docs/BUG_REGISTER.md`/`docs/RELEASE_SOP.md` on future edits.
