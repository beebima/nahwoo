# NAHWOO V0.1.8.23 — Bank Latihan 24.000 Soal (Draft Review)

**Tanggal:** 4 November 2026
**Paket Android:** id.sejutasantri.nahwoo
**Versi:** 0.1.8.23 (versionCode 30)
**Pemicu:** Gus Bee meminta 24.000 soal segera dimasukkan ke aplikasi; review isi soal menyusul langsung di aplikasi.

## Perubahan
- Tambahan 24 level × 1.000 soal, 50 paket × 20 soal/level: 24.000 ID unik dan 1.200 paket.
- Ruang Latihan → **Buka Bank 24.000 Soal**, pembaca Arab, enam opsi A–F, dua hint, penanda revisi, catatan per ID, dan salin laporan catatan.
- Data dimuat per level melalui JS asset offline, bukan memuat 24.000 soal bersamaan. Pilihan/catatan disimpan lokal.
- Evaluasi 4.800 soal, materi, kamus dan 10.000 mufradat tidak diubah.
- Level 01 memakai pemetaan sublevel P0 V1.1; Level 04–10 memakai PUBLIC hasil sanitasi P0 V1.1.
- Level 02 hanya memiliki MASTER pada lokasi produksi; konversi menggunakan whitelist field tampilan, **tanpa** kunci jawaban / alasan / metadata internal.
- Arsip MASTER, kunci/pembahasan reviewer, token/kredensial dan laporan privat tidak ditambahkan ke repository publik ataupun APK.

## Batas perilaku
Mode baru ini untuk **peninjauan konten**. Jawaban yang dipilih tersimpan tetapi tidak dinilai; kunci dan pembahasan internal tidak dibundel. Status konten **DRAFT_REVIEW**, bukan materi tervalidasi pakar maupun rilis produksi.

## Pintu uji
- Static QA: scripts/qa-qbank24-review.js memeriksa 24.000 ID, 1.200 paket, field publik, ID pada setiap paket, P0 Level 01, antarmuka dan versi.
- QA evaluasi existing: scripts/qa-qbank-v21.js tetap wajib lulus.
- GitHub Actions: Build Nahwoo Android Debug APK. Build dan pengujian fisik Android harus dibuktikan dari run serta perangkat, bukan disimpulkan dari commit.
- Pemeriksaan konten lebih lanjut: petunjuk terlalu eksplisit (103 kandidat), potensi pengulangan dan variasi sublevel, harakat, jawaban ambigu, serta kebenaran gramatikal.

## Regresi yang dicegah
Nama paket, 4.800 evaluasi terpisah, data progres yang telah tersimpan, Smart Reader, navigasi belakang, catatan dan Kamus Mini, font RTL dan dark mode.
