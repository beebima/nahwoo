# Catatan Rilis Nahwoo V0.1.8.9 — Inline Markdown Renderer

**Tanggal:** 2026-11-02 WIB  
**Status:** PATCH SOURCE + unit test lokal; GitHub/Actions dan APK akan diverifikasi terpisah.
**Sebelum:** V0.1.8.8 / versionCode 15, commit `b6e9ee3eb096152c42a5da980d819bacfb28be29`.  
**Sesudah:** V0.1.8.9 / versionCode 16 (SHA commit akan tercatat oleh GitHub).

## Masalah N-016

Pada materi _Tiga Keluarga Kata_ (Level 01) penegas `**kenali dulu keluarga katanya: isim, fi‘il, atau harf.**` masih menampilkan tanda `**`. Sebab: penanda Markdown disimpan dalam potongan `segments` terpisah dan renderer lama hanya mengikuti `marks`, bukan mem-parsing delimiter lintas potongan. Audit sumber GitHub mendeteksi marker `**` juga di Level 02, 16, 19, dan 23.

## Yang diubah

- Renderer `nwTextMixed` / `nwSegments` menggunakan parser rich-text lintas runs, tetap mempertahankan *bold/italic* dari `marks`, teks Arab, HTML escaping, dan tampilan semantik lama.
- `scripts/qa-richtext.js` menjadi tes otomatis 24 level × 10 sublevel, seluruh 4.800 soal, plus fixture quote Arab dan percobaan HTML injection.
- `.github/workflows/android-debug.yml` menjalankan tes di GitHub Actions **sebelum** tahapan build Android.
- `docs/BUG_REGISTER.md` (N-016), `docs/RELEASE_SOP.md`, dan `docs/DEVELOPMENT_LEDGER.md` diperbarui.

## Yang tidak diubah

- 24 level, 240 sublevel, 4.800 soal, bank mufradat, rotasi kartu Beranda, navigasi, lisensi, iklan, font, dan versi data.

## Bukti & risiko

- **Unit test lokal fixture:** LULUS (satu blok quote terpotong lintas segmen, Arab + italic, pengamanan HTML).
- **GitHub Actions:** BELUM DIUJI sampai log workflow tersedia.
- **APK Android:** BELUM DIUJI; harus preview kembali Level 01 di bagian Tiga Keluarga Kata.
- **Risiko:** kode Markdown tak berpasangan di sumber. QA mengaudit marker dan renderer menahan kebocoran `**`; revisi editorial tetap diperlukan bila konten malformed.
