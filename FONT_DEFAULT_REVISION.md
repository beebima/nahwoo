# Nahwoo V0.1.7 — Revisi 2: Default Font

Default untuk instalasi baru / pengguna tanpa pengaturan tersimpan:
- Sistem: 16 px
- Konten Latin: 16 px
- Konten Arab: 45 px

Preferensi font pengguna yang sudah tersimpan di localStorage tetap dipertahankan, tidak ditimpa. Pengguna lama yang sudah pernah menyetel ukuran akan tetap melihat ukuran pilihannya. Versi Android tidak berubah (V0.1.7).
