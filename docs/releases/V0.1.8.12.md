## Bug / risiko

- **N-020:** schema V4 berbeda dari schema runtime V0.1.8.11: `material_blocks[].text` dan `questions[].options[].text` perlu dipetakan ke `blocks[].segments` dan `options[].segments`, kalau tidak materi/opsi tampil kosong.
- **N-021:** jawaban lama (state `nahwoo_eval_v0185`) tidak berlaku setelah evaluasi diganti. Pakai namespace `nahwoo_eval_v4_01812` hanya untuk Level 01–08; jangan hapus progress global.
- **N-022:** Quick Check Level 07–08 dalam sumber hanya memiliki `question`; tidak boleh mengarang umpan balik, sehingga detail jawaban tidak ditampilkan.
- **N-023:** sumber memberi contoh Arab pedagogis dengan status editorial, bukan kutipan kitab otentik; butuh telaah ahli nahwu/pendidik.
- Privasi kunci: pemisahan JS public dan keys menunda tampilan kunci sampai submit, tetapi bundle offline APK masih dapat dibongkar; jangan mengklaim keamanan backend.
